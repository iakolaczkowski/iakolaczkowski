# Hi, I'm Istefan Kolaczkowski

Finance student at **Oregon State University** (Class of 2028), focused on quantitative trading,
financial modeling and the Python tooling that connects them.

### What I work on
- **Systematic futures trading.** I design and validate intraday strategies on CME index futures,
  using walk-forward testing, out-of-sample gates and placebo tests to separate real edges from noise.
- **Backtesting infrastructure.** Event-driven, tick-level simulation on NautilusTrader with
  Databento market data.
- **Corporate finance modeling.** WACC, CAPM beta estimation, DCF valuation and payout analysis
  in Excel, with data from FactSet.

### Featured project
**[nautilus-futures-backtest](https://github.com/iakolaczkowski/nautilus-futures-backtest)**:
a futures backtesting framework plus a documented research process. It includes a Python rebuild
of the TradingView Strategy Tester that matches it to the cent over about 1,000 trades, and a
write-up of ten strategy ideas the tests rejected and why.
